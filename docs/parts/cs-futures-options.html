Options on futures

Black-76: Call = D[FN(d1) − KN(d2)], Put = D[KN(−d2) − FN(−d1)]
Bachelier (STIR): Put = D[(K−F)N(−d) + σN√T n(d)], d = (F−K)/σN√T
D = e−rT premium-style, 1 futures-style. PV = qty × price × point value

Greeks: delta in futures contracts, gamma (huge for weeklies), vega per vol point or per bp normal vol, theta. Point values: crude $1,000, E-mini Nasdaq $20, 5Y note $1,000 (strikes in 32nds, premium in 64ths), 3M SONIA £1,250. Put on STIR price = call on rate.
