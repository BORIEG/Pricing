Attachment / detachment
The pool-loss levels where a tranche starts and stops absorbing losses.
Equity, mezzanine, senior
Tranches ordered from first-loss (riskiest) to last-loss (safest).
Expected tranche loss
The average fraction of a tranche lost by a date, over all default scenarios.
Default correlation
How much companies tend to default together. It sets the shape of the pool loss distribution.
Base correlation
The market convention of quoting one correlation per base (0–K%) tranche.
Large homogeneous pool
The one-factor Gaussian model with very many identical names, which gives pool loss in closed form for each state of the economy.
